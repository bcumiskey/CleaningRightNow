Cleaning Right Now - Testing Checklist

Tester: _______________________ Date: _______________________

Quick Smoke Test (5 minutes)

  • Register admin account
  • Add 1 property with photo
  • Create 1 job for the property
  • Add 1 team member
  • Log in as worker, view job
  • Create 1 incident note with photo
  • Log back in as admin, view the note

1. Authentication

  • Go to /register - Create admin account
  • Log out and log back in at /login
  • Verify redirect to dashboard after login
  • Test invalid login (wrong password)

2. Dashboard

  • Stats cards display correctly
  • Today's jobs section loads
  • Recent activity shows (if any)

3. Properties

  • Add a new property with all fields
  • Upload a property photo (tests Vercel Blob)
  • Edit an existing property
  • Delete a property
  • Search/filter properties

4. Jobs

  • Create a new job (assign to property)
  • Assign team member to job
  • Edit job details
  • Mark job as completed
  • Verify job appears on calendar

5. Team/Workers

  • Add a team member with email/password
  • Set their hourly rate
  • View team member details
  • Log out, then log in as worker at /worker
  • Verify worker can see assigned jobs
  • Verify worker can see pay statements

6. Notes/Incidents

  • As worker: Go to property reference page
  • Create note with description and severity
  • Upload photo(s) to the note
  • As admin: View notes at /notes
  • Filter notes by property
  • Filter notes by severity
  • View note details with photos
  • Download incident PDF report

7. Invoices

  • Create an invoice for a property
  • Add line items to invoice
  • Preview invoice PDF
  • Download invoice PDF
  • Send invoice via email (tests Resend)
  • Mark invoice as paid

8. Push Notifications

  • Go to Settings page
  • Click enable push notifications
  • Browser permission prompt appears
  • Toggle shows "Enabled" state after allowing
  • Can disable notifications

9. Calendar

  • View calendar page
  • Jobs appear on correct dates
  • Can navigate between months
  • Export calendar (ICS sync)

10. Settings

  • Update company name
  • Upload company logo
  • Update contact information
  • Save and verify changes persist

11. Linens Management

  • View linen inventory
  • Filter by category
  • Update linen quantities

12. Reports

  • View reports page
  • Generate revenue report
  • Filter by date range
